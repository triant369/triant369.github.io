Smart Irrigation IoT System

Autonomous Soil Monitoring & Water Control using ESP32

Sistem Irigasi IoT Cerdas

Monitoring Kelembaban Tanah & Kontrol Air Otomatis berbasis ESP32

Overview

This system automates irrigation using real-time soil moisture sensing and embedded decision-making. The device operates independently using edge computing, allowing automatic water control without cloud dependency.

Gambaran Sistem

Sistem ini mengotomatisasi penyiraman berdasarkan sensor kelembaban tanah secara real-time. Perangkat bekerja secara mandiri menggunakan edge computing tanpa ketergantungan cloud.

Key Features

  • Real-time soil moisture monitoring
  • Automatic irrigation based on threshold
  • Telegram-based remote control
  • Pump safety timeout protection
  • Portable power system (powerbank supported)
  • Edge computing (no cloud dependency)

Fitur Utama

  • Monitoring kelembaban tanah real-time
  • Penyiraman otomatis berbasis threshold
  • Kontrol jarak jauh via Telegram
  • Proteksi timeout pompa
  • Dapat menggunakan powerbank
  • Edge computing tanpa cloud
