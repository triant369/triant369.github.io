Smart Irrigation IoT System

Autonomous Soil Monitoring & Water Control using ESP32

Sistem Irigasi IoT Cerdas

Monitoring Kelembaban Tanah & Kontrol Air Otomatis berbasis ESP32

Overview

This system is designed to automate irrigation using real-time soil moisture sensing and embedded decision-making. The device operates independently using edge computing, allowing automatic water control without reliance on external servers.

Gambaran Sistem

Sistem ini dirancang untuk mengotomatisasi penyiraman menggunakan sensor kelembaban tanah secara real-time dan pengambilan keputusan berbasis embedded. Perangkat bekerja secara mandiri menggunakan edge computing tanpa ketergantungan pada server eksternal.

Key Features

  • Real-time soil moisture monitoring
  • Automatic irrigation based on threshold
  • Telegram-based remote control
  • Pump safety timeout protection
  • Portable power system (powerbank supported)
  • Edge computing (no cloud dependency)

Fitur Utama

  • Monitoring kelembaban tanah secara real-time
  • Penyiraman otomatis berbasis ambang batas
  • Kontrol jarak jauh melalui Telegram
  • Proteksi timeout pompa
  • Dapat menggunakan powerbank
  • Edge computing tanpa cloud
